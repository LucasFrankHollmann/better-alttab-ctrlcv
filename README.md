# AltTab CtrlCV

Aplicação de bandeja (tray) em C# usando Win32 API.

## Como executar

1. Abra o terminal na pasta do projeto.
2. Execute `dotnet run`.

## Comandos

- Clique com o botão esquerdo no ícone da bandeja para ver uma mensagem.
- Clique com o botão direito no ícone da bandeja para abrir o menu e sair.
